# Animal Image Classification (5 Species)

This repository contains a PyTorch implementation of a Multi-Class Convolutional Neural Network (CNN) designed to classify images of 5 different animal species.

# Dataset
- Dataset: `miadul/animal-image-classification-5-species` (Kaggle)
- Source: Downloaded automatically via `kagglehub`
- Classes:** 5 Animal Species

# Requirements & Setup

Before running the code, install the required dependencies:

bash
pip install torch torchvision kagglehub
